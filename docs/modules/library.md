## Library (CsoundLib)

512 slots = banks A (0..127), B (128..255): user; C (256..383): SQ8L factory; D (384..511):
SQ80 factory in 384..423, INIT in the rest. Index = bank*128 + program.

There is **one global library** per DLL (shared by all plugin instances). It is created when
the DLL is loaded and destroyed when it is unloaded:

1. `FUN_004550b0(lib, true)`: header INIT + all 512 slots INIT, clean := 0.
2. `CsoundLib_v005` (restore): factory banks (`FUN_004552a4`: bank C from the CpackRle25
   blob at 0x489c54, which is a type-2 library image of 128 programs; bank D = FUN_00454aec
   of the 40 raw SQ80 programs at 0x493324 with (1, 0, 4, -12)); notify(-1); then
   `SQ8L\SQ8L_backup.dat` is loaded as a library file; if that fails (no file, empty,
   unknown type, bad magic) banks C and D are **copied into A and B**; clean := 1.
3. At unload `CsoundLib_v006` writes the library file image to `SQ8L_backup.dat`; clean := 1.

C++: `SoundLibrary()` = 1 + 2 without file; `SoundLibrary(backupBytes)`;
`restoreBackup(data, size)`; `saveBackup()` returns the bytes to write. The plugin must keep
one library per process and do the file I/O itself.

### File formats

All files are raw images, no compression:

| file | layout |
|---|---|
| library (`*.8XL`, `SQ8L_backup.dat`), 0x21c3c bytes | 0x3c header + 256 programs (banks A, B) |
| bank, 0x10e3c bytes | 0x3c header (count 0x80) + 128 programs |
| pre-0.90 library/bank ("type 1") | dword 1, 16 bytes, 128 programs of 0x220 bytes (old format, converted with `convertOldProgram`) |

Header (0x3c bytes, `SoundLibrary::header()`): `+0 int32 type = 2`, `+4 ShortString
"\x08SQ8L.LIB"` (exact match required), `+0x14 int32 count` (0x100 for libraries, 0x80 for
banks), `+0x18 ShortString` library name ("INIT"), rest 0. Saving copies the library's
current header (the header of the last loaded library file, count forced to 0x100).

Loading (`loadLibrary` = FUN_00455534, `loadBank` = FUN_00455884):
* type 1: 128 old programs converted into bank A (library) or the given bank (bank; -1 -> A,
  >= 4 fails);
* type 2: magic must match, else fail without any change; library: header copied, then
  min(count, 256) programs into slots 0..; bank: min(count, 128) programs into the bank
  (bank < 0 -> A, >= 4 fail). The library object itself allows loading into C/D; only the
  editor refuses ("Bank is write protected", `isBankWriteProtected(bank) = bank >= 2`);
* other types: nothing loaded, result false.
There are no size checks in the original (it reads past short files); the C++ reads missing
bytes as 0. Every load (also a failed type-1/unknown-type load) clears the clean flag and
notifies listeners with -1; a magic mismatch returns before that.

Other operations: `initLibrary(false)` = editor "Init library" (header + banks A, B), 
`initBank(b)` (no notification), `copyBanks`, `writeProgram(index, p)` (FUN_00455da8: refuses
index >= 256, notifies with the index), `readProgram`, `programName(index)` (the ShortString
with its full length byte), `saveLibrary()`/`saveBank(b)` (also clear the clean flag).

Verified: library state after DLL load (all 512 programs, header, flag), library/bank
save images, loads of valid/old/broken images with various counts into all banks, init,
writes (incl. protected slots), names, backup file written by the original into
`oracle/sandbox/`, restore from valid/old/corrupt/missing backup files.

## SysEx (SQ80 / ESQ-1)

Dump header `F0 0F 02 <channel> <type>`: type 1 single program (210 bytes: 5 + 204 nybbles
+ F7), type 2 = 40 programs (8166 bytes). `parseHeader` (FUN_00453fb0) only checks F0 0F 02
and returns data[4]; `writeHeader` (FUN_00453fd8) accepts types 1 and 2.

* Single import, edit buffer (`EditBuffer::importSysex`, FUN_00460c68): with header check
  the type must be 1; size >= 0xd1; ring advance, conversion into the current slot (starting
  from INIT, the extension block becomes INIT's), modified := 1, event 0. The editor first
  tries with the header check, then (after asking) without.
* Single export (`exportSysex`, FUN_00460d10): 210 bytes, channel 0, `programToNybbles`.
* Bank import (`SoundLibrary::importSysexBank`, FUN_00455a8c): optional header check (type
  2), size >= 0x1fe5, 40 programs into consecutive slots from `startIndex` (no write
  protection check at this level; stops at an invalid index, keeping what was converted).
* Bank export (`exportSysexBank`, FUN_00455b70): 8166 bytes, channel 0; the editor requires
  40 programs at the position.
* Conversions `programFromNybbles`, `programToNybbles(esq1)` (the original always passes
  esq1 = false; true clamps waves to 0..31), `programFromSq80Bytes`, the source mapping and
  the name character set are described in `program.md`. MIDI device I/O (winmm) is not
  ported; only the byte conversion.

Verified: exhaustive source mapping (256 + 65536 values), 6000 names both ways, export of all
512 library programs + 600 random records (both esq1 modes), import of 1900 nybble streams
(exports, random nybbles, random bytes), the 40 bank D programs and 600 random raw records.

## Edit buffer (CeditBuf)

Object layout (also the `saveState/loadState` image used by the tests):

| offset | field |
|---|---|
| +0x004 + i*0x21c | program slots 0..3 (ring) |
| +0x874 | slot 4: program saved while COMPARE is active |
| +0xa90 | ring index (current slot) |
| +0xa94 | pointer to the current program |
| +0xa98 | extension buffer (0x6c bytes, mirror of program+0x1b0) |
| +0xb04 | extension buffer saved while COMPARE is active |
| +0xb70 | current bank (0..3) |
| +0xb74 | current program number (0..127, -1 possible, see below) |
| +0xb7c | CparamEditor (base = current program + 0x22) |
| +0xb84 | "keep extension buffer" flag (never set in 0.91b) |
| +0xb85 | modified flag |
| +0xb88 | COMPARE active (int) |
| +0xb8c | chunk buffer (allocated once, 0x23b bytes) |
| +0xb98 | parameter-change forwarding callback (never registered) |
| +0xba8/+0xbac/+0xbb0 | owner callback (code, Self, user data), set by FUN_004610f4 |

**Ring:** every operation that brings a new program advances the ring first
(`FUN_00460498`: index = (index+1) & 3, current = slot[index], event 4 with the new slot,
event 5 with slot[(index+1)&3]). Voices keep pointers into the slots, so the previous program
stays valid while it releases; event 5 tells the owner which slot will be overwritten next.

**Extension buffer:** `captureExt` (FUN_00460868, after select/chunk/compare): buffer :=
program ext (unless +0xb84). `applyExt` (FUN_004608dc, before WRITE and getChunk): program
ext := buffer. SysEx import and INIT do not touch the buffer (pre-0.90 chunks are captured like new ones).

Operations (C++ name = original):

| C++ | original | behaviour |
|---|---|---|
| `EditBuffer(lib)` | FUN_004603b8 | slot 0 current, INIT in it, modified := 1, no event |
| `initProgram()` | FUN_00460554 | INIT button: INIT into the current slot (no ring advance), modified := 1, no event |
| `selectProgram(p, b)` | FUN_00460db8 | ring advance; read lib[b*128+p] (p < 0 / b < 0: current values); fail -> false (ring already advanced, no event 0); else prog := p (even -1), bank := b if b >= 0, modified := 0, captureExt, event 0 |
| `selectIndex(i)` | master FUN_004631f0 | VST setProgram: 0..511 -> select(i & 127, i >> 7); others ignored |
| `writeProgram(p, b)` | FUN_00460e74 | WRITE: applyExt; library write (fails for banks C/D); on success prog/bank set, modified := 0, event 1 |
| `compare(p, b)` | FUN_00460f2c | if not comparing: slot 4 := current, ext backup := ext; ring advance; load lib program; ok: comparing, captureExt; else compareOff(); event 2 |
| `compareOff()` | FUN_0046104c | if comparing: ring advance, current := slot 4, ext := backup, not comparing, event 3 |
| `getChunk()` | FUN_00460b84 | see below (applyExt side effect) |
| `setChunk(d, n)` | FUN_00460b40 | n = 0x23b: new chunk; n = 0x220: pre-0.90 chunk; else 0 |
| `importSysex` / `exportSysex` | FUN_00460c68 / FUN_00460d10 | see SysEx |
| `setName(w, s)` / `name(w)` | FUN_0046072c / FUN_004606b4 | ShortString[15] at +2 (w=0) or +0x12 (w=1); no modified flag, no event |
| `setBank(b)` | FUN_00460630 | clamp 0..3 |
| `libraryIndex(p, b)`, `splitIndex` | FUN_00460658, FUN_00460674 | |
| `resetExtZone(z)` | FUN_004605ac | z = 0/1 (-1: both), modified := 1 |
| `setParamValue(i, v)` | CparamEditor FUN_0045fb30 + FUN_0046095c | write through the parameter table, modified := 1, no event |
| `programWord()` | FUN_0046093c | prog << 16 (used by the master when a voice starts) |

**Events** (`Listener(Event, const Program* slot)`, original FUN_00460998 -> owner callback
`code(Self, userData, event, arg)`): 0 program loaded (select, chunk, SysEx import),
1 written to the library, 2 COMPARE on, 3 COMPARE off, 4 new current slot, 5 next slot.
The master (`FUN_00461cac`) registers `FUN_00463230` with `FUN_004610f4(editbuf, master,
FUN_00463230, master)`; it dispatches 0 -> FUN_0046328c (FUN_00462488 + host notify
FUN_00461fb8(0,0) + FUN_00461fd8(2,1,0)), 1 -> FUN_00461fb8(0,0), 2/3 -> FUN_00462488,
4 -> FUN_00462e6c(slot), 5 -> FUN_00462e9c(slot).

### Host chunk (effGetChunk / effSetChunk)

`CSynth_v018` (getChunk) returns `FUN_00460b84(editbuf)`; only the edit buffer is saved
(`isPreset` is ignored). Format, 0x23b = 571 bytes:

| offset | content |
|---|---|
| 0x00 | int32 2 |
| 0x04 | ShortString "\x09SQ8L.EDIT" (10 bytes), then zeros |
| 0x18 | int16 current program number (+0xb74) |
| 0x1a | modified flag (0/1) |
| 0x1b..0x1e | 0 (the port uses 0x1b/0x1c, below) |
| 0x1f | the 540-byte program (after applyExt) |

**Port addition.** `Synth::getChunk` writes the instance's playable voices (OPTIONS →
Polyphony, 0 = set by the program's `VOICES`) into two of the spare header bytes: `0x1b` =
`'V'`, `0x1c` = 1..64. `EditBuffer` itself never touches them, and they are only written when
there is an override, so an ordinary chunk is byte for byte the original's. The original
validates the type, the magic and `0x01..0x03` only, so it loads such a chunk and ignores the
two bytes; `Synth::setChunk` reads them back and puts an instance whose chunk has none back to
"set by the program". The chunk is what every plugin format saves (the VST2 chunk is these
bytes verbatim, `DISTRHO_PLUGIN_VST2_RAW_CHUNK_KEY`), so the override is recalled with a
project in all of them.

`CSynth_v019` (setChunk) calls `FUN_00460b40(editbuf, data, size)`: size 0x23b: type 2 and
exact magic required, ring advance, program copied, captureExt, prog := int16 at 0x18,
**modified := 1** (the saved flag is ignored), event 0; size 0x220: pre-0.90 chunk = old
program record with word 1 at +0x200 (converted, modified := 1, event 0); other sizes are
refused. On success CSynth returns 0 and sets its +0xb4 flag, which makes it **ignore the next
effSetProgram** (hosts call setProgram after setChunk); a failed setChunk returns -1. The
bank number is not saved.

### VST program interface (CSynth, for the plugin integrator)

* numPrograms = 512 (`AudioEffectX(…, 0x200, 0)`), program change MIDI messages are ignored.
* `setProgram(i)` (CSynth_v011): AudioEffect::setProgram, then unless the +0xb4 flag is set
  (cleared instead) `master FUN_004631f0(i)` -> `selectIndex(i)`.
* `getProgramName` (CSynth_v013): edit buffer name; `setProgramName` (CSynth_v012):
  `setName(0, s)` (15 chars) + host notification FUN_00461fd8(2,1,0).
* `getProgramNameIndexed(category, i)` (CSynth_v047): `library.programName(i)` for 0..511,
  "" otherwise.

Verified (5000 random edit-buffer operations in lockstep with the original, plus targeted
VST dispatcher sequences): complete edit-buffer state after every operation, event sequences,
chunks (direct and via effGetChunk/effSetChunk/effSetProgram), names, SysEx single
import/export, parameter writes.

## Integration notes

* A new plugin instance: the master constructor creates the edit buffer (INIT, modified) and
  registers its event callback, then calls `selectProgram(0, -1)` (A000, modified := 0,
  events 4, 5, 0). Verified against the emulated startup state.
* Keep one `SoundLibrary` per process, constructed from the `SQ8L_backup.dat` bytes (or
  none), and write `saveBackup()` when the last instance goes away.
* The voices must read the program through `EditBuffer::current()` and handle events 4/5
  (slot changes) like the original master does.
* Parameter edits do not send events; only the modified flag changes.
* The second name (`name2`, +0x12) and the extension zones are kept but have no GUI in 0.91b.
